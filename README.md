# JapaChão

JapaChão foi um projeto criado para praticar meus novos conhecimentos de Flask, e sendo assim, minha primeira "aplicação" com back-end.

O *app* é um fórum anônimo onde os usuários podem fazer publicações, anexar imagens e responder uns aos outros.

Essa aplicação é bem simples e até que antiga ─ no momento que estou escrevendo isso, faz uns 4 meses que fiz ele.

É algo bem amador, porém ajudou a ampliar meu conhecimento sobre Python, Flask, SQLite e JavaScript.
